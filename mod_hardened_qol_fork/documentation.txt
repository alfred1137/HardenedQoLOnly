# Requirements

- Reforged (>= 0.9.0)
- MSU
- Dynamic Spawns (>= 0.5.0)

# Documentation for Codebase

## API:
- Backend features that don't change anything by themselves
- Re-writes of vanilla features/properties. This might sometimes slightly change how they behave
- API stuff will usually not touch any leaf-scripts
## Non-API:
- Everything else

# Scope of this fork

This is a **QoL-only fork** of Hardened. All of Hardened's balance and mechanic
overhauls (perk reworks, item/unit/party rebalances, economy/price changes,
stamina/initiative/weight rework, world/contract/faction difficulty scaling,
new perks, reach overhaul) were removed. The game balance equals Reforged.

Only QoL improvements and bug fixes are kept. See `README.md` for the list of
retained features. The full upstream changelog lives at
https://github.com/Darxo/Hardened — the entries there mostly describe changes
that do NOT exist in this fork.

# Known Issues

- Hitchances of Lunge-Like attacks can be inaccurate, as the act of moving next to your target can enable/disable various effects
- Removing or adding the mod on an existing save is generally safe, because no balance data is baked into the save; verify on a test save first

# Compatibility

- Safe to remove from- and add to any existing savegames (verify on a test save)
- Coexists with upstream Hardened (distinct mod ID `mod_hardened_qol_fork`)

# Changelog

## 1.22.5

- Port upstream 1.22.5 QoL and bug fixes.
- Add: minus sign formatting — negative numbers use en-dash with non-breaking spaces for readability in tooltips (Squirrel + JS hooks).
- Add: charmed unit targeting improvements — temporarily charmed units are less likely to be targeted by former allies (target attraction reduction + AI query value override).

### Deferred from upstream 1.22.5 (not yet integrated)

The following upstream 1.22.5 features were reviewed but deferred for separate integration:

- **Stat breakdown system** (`HD_addPropertyBreakdown`, `SupportedBreakdowns` table, `getBaseAttributesTooltip` rewrite, Reach nested tooltip fix) — major QoL feature (~240 lines) that adds per-skill breakdown tooltips for every character screen stat. Medium risk due to size and tooltip_events.nut rewrite. Replaces current Fatigue-only tooltip override.
- **`HD_getInitiativeModifierFromFatigue()`** API helper — only used by upstream's `getInitiative` override (balance: fatigue-initiative formula) and stat breakdowns. Neither in scope.
- **`HD_hide()` MSU setting API** (`hooks_early/mods/msu/settings.nut`) — allows hiding/disabling MSU settings at runtime. Only use case is disabling incompatible Reforged contract settings, which our QoL purge already removed.

## 1.22.4-patch.3

- Remove: upstream Hardened world clock schedule (`TimeOfDay` label array, `Const.World.TimeOfDay` index table, ambient lighting override, `DayTime` concept tooltip). Vanilla clock restored; feature added no meaningful QoL and was phase-shifted.
- Change: build script install instruction corrected ("drop zip into data/ as-is").

## 1.22.4-patch.2

- Fix: JS SyntaxError in `world_combat_dialog.js` — trailing comma in function parameter list rejected by Coherent GT ES5 parser. Combat dialog show/hide velocity-stop override was dead; cancel + immediate re-show triggered invisible-window freeze on world map.

## 1.22.4-patch.1

- Fix: in-game clock period labels being phase-shifted (night read as afternoon, dawn as midday, etc.). Root cause: upstream Hardened ships `TimeOfDay` label array and `Const.World.TimeOfDay` index object rotated one bucket against the `floor(Hours / 2)` mapping. Remapped both to Hardened schedule: Sunrise 0-1, Morning 2-7, Midday 8-9, Afternoon 10-15, Sunset 16-17, Dusk 18-19, Midnight 20-21, Dawn 22-23. **Dropped in patch.3** (vanilla clock restored).

See `README.md` and https://github.com/Darxo/Hardened (upstream). This fork
tracks upstream release 1.22.0 minus all balance/mechanic overhauls, and
incorporates upstream fixes through 1.22.5 (null-guard hardening, world map
UI freeze fix, minus sign formatting, charm targeting QoL). It is a
faithful QoL/fix repackaging of upstream, provided as-is with no commitment to
future maintenance.
